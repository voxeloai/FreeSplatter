## What didn't (4 layers, all patched)

| # | Symptom | Root cause | Fix |
|---|---|---|---|
| 1 | `ModuleNotFoundError: No module named 'diffusers_modules'` at app.py boot during `DiffusionPipeline.from_pretrained` | `init_hf_modules` doesn't always re-add `HF_MODULES_CACHE` to sys.path before import | `.pth` file in venv site-packages: `/workspace/envs/freesplatter/lib/python3.10/site-packages/_hf_modules_path.pth` containing `/workspace/hf-cache/modules` |
| 2 | `FileNotFoundError: Could not find examples directory: examples/img_to_3d` | Upstream `.gitignore` excludes `examples/` so the fork never had them | `mkdir -p` 6 empty dirs (img_to_3d, views_to_3d, views_to_scene, text_to_img_to_3d, instant3d, text_to_3d) |
| 3 | `TypeError: argument of type 'bool' is not iterable` in `gradio_client/utils.py:880` `get_type` | Newer JSON Schema `additionalProperties: True` (a bool) reaches `get_type` which assumes dict | Patch: add `if not isinstance(schema, dict): return None` at top of `get_type` |
| 4 | `gradio_client.utils.APIInfoParseError: Cannot parse schema True` then `ValueError: When localhost is not accessible` | Same root cause as #3, but `_json_schema_to_python_type` recursively hits the bool too | Patch: add `if isinstance(schema, bool): return "Any"` at top of `_json_schema_to_python_type` |

All 4 fixes baked into `scripts/bootstrap.sh` step 6.5 (idempotent, runs every boot to survive venv reinstalls). Tried but didn't help: `show_api=False` in `app.py` launch — gradio's internal self-test still triggered the API introspection. Reverted that change.
